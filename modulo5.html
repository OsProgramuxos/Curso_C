Módulo 5 - Ponteiros

Bem-vindo ao Módulo 5. Agora vamos estudar ponteiros, um recurso importante da linguagem C que permite trabalhar com endereços de memória e alterar valores de forma mais direta.

  • Endereço de memória
  • Declaração de ponteiros
  • Operadores & e *
  • Acesso ao valor apontado
  • Alteração de variáveis por ponteiros
  • Ponteiros em funções

Endereço de memória

Cada variável ocupa um espaço na memória. O operador & mostra o endereço onde essa variável está guardada.

Exemplo: mostrando o endereço de uma variável


#include <stdio.h>

int main() {
  int numero = 25;

  printf("Valor da variavel: %d\n", numero);
  printf("Endereco da variavel: %p\n", &numero);

  return 0;
}

Usando ponteiros

Um ponteiro é uma variável que guarda o endereço de outra variável. O operador * acessa o valor que está naquele endereço.

Exemplo: endereço e valor apontado


#include <stdio.h>

int main() {
  int numero = 25;
  int *ponteiro;

  ponteiro = &numero;

  printf("Valor da variavel: %d\n", numero);
  printf("Endereco guardado no ponteiro: %p\n", ponteiro);
  printf("Valor apontado pelo ponteiro: %d\n", *ponteiro);

  return 0;
}

Exercícios

1) Crie um programa que altere o valor de uma variável usando ponteiro.


#include <stdio.h>

int main() {
  int numero = 10;
  int *ponteiro = &numero;

  *ponteiro = 50;

  printf("Novo valor: %d", numero);

  return 0;
}

2) Crie uma função que troque dois valores usando ponteiros.


#include <stdio.h>

void trocar(int *a, int *b) {
  int auxiliar;

  auxiliar = *a;
  *a = *b;
  *b = auxiliar;
}

int main() {
  int x = 10;
  int y = 20;

  printf("Antes: x = %d, y = %d\n", x, y);

  trocar(&x, &y);

  printf("Depois: x = %d, y = %d\n", x, y);

  return 0;
}
