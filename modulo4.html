Módulo 4 - Funções

Bem-vindo ao Módulo 4. Neste módulo você vai aprender a criar funções em C para dividir o programa em partes menores, reutilizar código e deixar a lógica mais organizada.

O que é uma função?

Uma função é um bloco de código criado para executar uma tarefa específica. Em C, todo programa começa pela função main, mas você também pode criar suas próprias funções.

Exemplo: função simples


#include <stdio.h>

void mostrarMensagem() {
  printf("Bem-vindo ao estudo de funcoes em C!\n");
}

int main() {
  mostrarMensagem();

  return 0;
}

Funções com parâmetros

Parâmetros são valores enviados para uma função. Eles permitem que a função trabalhe com dados diferentes a cada chamada.

Exemplo: função para somar dois números


#include <stdio.h>

int somar(int a, int b) {
  return a + b;
}

int main() {
  int resultado;

  resultado = somar(10, 5);

  printf("Resultado da soma: %d", resultado);

  return 0;
}

Exercícios

1) Crie uma função que receba dois números e retorne o maior.


#include <stdio.h>

int maiorNumero(int a, int b) {
  if (a > b) {
    return a;
  }

  return b;
}

int main() {
  int x;
  int y;

  printf("Digite o primeiro numero: ");
  scanf("%d", &x);

  printf("Digite o segundo numero: ");
  scanf("%d", &y);

  printf("Maior numero: %d", maiorNumero(x, y));

  return 0;
}

2) Crie uma função que receba uma nota e diga se o aluno foi aprovado.


#include <stdio.h>

void verificarAprovacao(float nota) {
  if (nota >= 6) {
    printf("Aluno aprovado");
  } else {
    printf("Aluno reprovado");
  }
}

int main() {
  float nota;

  printf("Digite a nota: ");
  scanf("%f", &nota);

  verificarAprovacao(nota);

  return 0;
}
